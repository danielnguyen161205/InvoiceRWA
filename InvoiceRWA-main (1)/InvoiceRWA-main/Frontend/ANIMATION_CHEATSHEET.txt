┌─────────────────────────────────────────────────────────────────────────────┐
│ 📦 FILES STRUCTURE                                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ CSS Files:                                                                  │
│   ├─ animations.css        → Core animations (fade, slide, bounce, etc.)   │
│   ├─ transitions.css       → UI transitions (buttons, cards, modals)       │
│   ├─ effects.css           → Special effects (glass, gradients, glow)      │
│   └─ animations-master.css → All-in-one import file                        │
│                                                                             │
│ JavaScript Files:                                                           │
│   ├─ scroll-animations.js  → Scroll-triggered animations                   │
│   └─ page-transitions.js   → Page transition system                        │
│                                                                             │
│ Config:                                                                     │
│   └─ tailwind.config.js    → Custom Tailwind animations & utilities        │
│                                                                             │
│ Documentation:                                                              │
│   ├─ ANIMATION_GUIDE.md    → Complete documentation                        │
│   ├─ ANIMATION_README.md   → Quick start guide                             │
│   └─ animation-showcase.html → Live demo                                   │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ ⚡ QUICK START                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. Import CSS (choose one):                                                │
│    <!-- Option A: All-in-one -->                                           │
│    <link rel="stylesheet" href="assets/css/animations-master.css">        │
│                                                                             │
│    <!-- Option B: Individual files -->                                     │
│    <link rel="stylesheet" href="assets/css/animations.css">               │
│    <link rel="stylesheet" href="assets/css/transitions.css">              │
│    <link rel="stylesheet" href="assets/css/effects.css">                  │
│                                                                             │
│ 2. Import JavaScript (before </body>):                                     │
│    <script src="assets/js/scroll-animations.js"></script>                 │
│    <script src="assets/js/page-transitions.js"></script>                  │
│                                                                             │
│ 3. Use classes in HTML:                                                    │
│    <div class="animate-fade-in-up delay-200">Content</div>                │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ ⏱️ DELAYS & DURATIONS                                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│ ANIMATION DELAYS                                                            │
│   .delay-100     → 0.1s delay                                              │
│   .delay-200     → 0.2s delay                                              │
│   .delay-300     → 0.3s delay                                              │
│   .delay-500     → 0.5s delay                                              │
│   .delay-1000    → 1s delay                                                │
│                                                                             │
│ ANIMATION DURATIONS                                                         │
│   .duration-fast   → 0.3s                                                  │
│   .duration-normal → 0.6s (default)                                        │
│   .duration-slow   → 1s                                                    │
│   .duration-slower → 1.5s                                                  │
│                                                                             │
│ EXAMPLE:                                                                    │
│   <div class="animate-fade-in-up delay-200 duration-slow">                │
│     Fades in up with 0.2s delay over 1s                                   │
│   </div>                                                                   │

┌─────────────────────────────────────────────────────────────────────────────┐
│ 📜 SCROLL ANIMATIONS (JavaScript)                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│ CSS CLASSES                                                                 │
│   .scroll-reveal        → Generic scroll reveal                            │
│   .scroll-reveal-up     → Reveal from bottom                               │
│   .scroll-reveal-down   → Reveal from top                                  │
│   .scroll-reveal-left   → Reveal from right                                │
│   .scroll-reveal-right  → Reveal from left                                 │
│   .scroll-reveal-scale  → Reveal with scale                                │
│                                                                             │
│ STAGGER CHILDREN                                                            │
│   .stagger-children     → Auto-stagger child elements                      │
│                                                                             │
│ CUSTOM ANIMATION                                                            │
│   data-scroll-animation="fadeIn 1s ease-out"                               │
│                                                                             │
│ COUNTER ANIMATION                                                           │
│   <span data-count="12500" data-decimals="0">0</span>                     │
│                                                                             │
│ JAVASCRIPT API                                                              │
│   // Parallax effect                                                       │
│   new ParallaxScroll('.image', { speed: 0.5 });                           │
│                                                                             │
│   // Smooth scroll                                                         │
│   new SmoothScroll({ duration: 800, offset: 80 });                        │
│                                                                             │
│   // Typing animation                                                      │
│   new TypingAnimation('#title', {                                          │
│     text: 'Welcome!',                                                      │
│     speed: 100                                                             │
│   });                                                                      │

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🎯 PRO TIPS                                                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. Combine classes for unique effects:                                     │
│    <div class="animate-fade-in-up delay-300 hover-lift shadow-primary">   │
│                                                                             │
│ 2. Use stagger for lists and grids:                                        │
│    <ul class="stagger-children">...</ul>                                  │
│                                                                             │
│ 3. Add scroll reveals to sections:                                         │
│    <section class="scroll-reveal-up">...</section>                        │
│                                                                             │
│ 4. Test on mobile devices for performance                                  │
│                                                                             │
│ 5. Respect user preferences (prefers-reduced-motion)                       │
│                                                                             │
│ 6. Don't overuse animations - less is more!                                │
│                                                                             │
│ 7. Use GPU acceleration for smooth animations:                             │
│    <div class="gpu-accelerated animate-...">                              │
│                                                                             │
│ 8. Combine with Tailwind utilities:                                        │
│    <div class="animate-fade-in-up p-6 bg-white rounded-xl shadow-lg">    │
