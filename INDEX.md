## 🎯 Learning Paths

### Path 1: First-Time User (30 minutes)
1. Read [QUICK_START.md](QUICK_START.md) (5 min)
2. Run `.\quick-setup.ps1` (10 min)
3. Run `.\start-all.ps1` (2 min)
4. Login and explore UI (13 min)

### Path 2: Developer Setup (2 hours)
1. Read [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md) (30 min)
2. Manual setup Backend (30 min)
3. Manual setup Blockchain (30 min)
4. Manual setup Frontend (20 min)
5. Test full workflow (10 min)

### Path 3: Bank Administrator (1 hour)
1. Read [README.md](README.md) overview (15 min)
2. Read [README_BANK_FINANCING.md](README_BANK_FINANCING.md) (20 min)
3. Read [QUICK_REFERENCE_BANK.md](QUICK_REFERENCE_BANK.md) (10 min)
4. Practice with API (15 min)

3. Study smart contracts (60 min)
4. Deploy and test (60 min)

## 📝 Documentation Standards

### File Naming
- `README*.md` - Main documentation
- `GUIDE*.md` - Step-by-step guides
- `QUICK*.md` - Quick references
- `*_README.md` - Feature-specific docs

### Structure
All docs should have:
1. ✅ Title and description
2. ✅ Table of contents (if long)
3. ✅ Code examples
4. ✅ Screenshots (when applicable)
5. ✅ Troubleshooting section
6. ✅ Version and date
